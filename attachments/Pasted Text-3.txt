スマホ版のテキスト選択・画像選択の無効化指示書

1. 修正の目的

スマホ版の操作中に、メニューなどを長押しするとブラウザ標準のテキスト選択が発生する問題を修正する。

特に画面拡大後のメニューで、長押しするとテキストの範囲選択のような状態になってしまうことが確認されている。

今後の液体演出の仮想スティック操作などにも影響するため、スマホ版全体について、ブラウザ標準のテキスト選択や画像選択・ドラッグを原則として無効化する。

スマホ版は、テキストや画像を選択するためのWebページではなく、タッチ操作を中心としたアプリとして扱うこと。

2. 適用範囲

スマホ版のアプリ画面全体を対象とする。

以下を含む。

* 通常画面
* 画像一覧
* 画像拡大表示画面
* 拡大表示中の各種メニュー
* メニューボタンやアイコン
* フォルダ・タグ関連の操作UI
* 画像アニメーション関連の操作UI
* ぷるぷるメーカー関連の操作UI
* 液体演出の💧アイコンと仮想スティック
* 各種ポップアップ・操作パネル
* その他のタッチ操作可能なUI

一部のメニューだけでなく、スマホ版全体に統一して適用すること。

PC版の操作性や選択機能には影響させないこと。

3. テキスト選択の無効化

スマホ版のアプリ画面内では、通常のテキスト範囲選択を無効化する。

CSSの user-select: none を基本として使用する。

必要に応じて以下も適用する。

* -webkit-user-select: none
* -webkit-touch-callout: none

長押ししても、文字列の選択範囲や選択ハンドルが表示されないようにする。

また、長押しによってテキスト選択が開始されないことを確認する。

4. 画像の選択・ドラッグの無効化

スマホ版の画像についても、ブラウザ標準の画像ドラッグや画像選択を無効化する。

* 画像を長押ししてもブラウザ標準の画像操作メニューを表示しない。
* 画像をドラッグしてもブラウザ標準の画像ドラッグを開始しない。
* 画像の選択状態を作らない。
* 画像をタッチした際に意図しないゴースト画像が表示されない。

必要に応じて画像要素に draggable="false" を設定する。

ただし、アプリ独自の画像操作は維持すること。

5. アプリ独自のタッチ操作は維持する

ブラウザ標準の選択操作を無効化しても、アプリ独自の操作を妨げないこと。

以下の機能は正常に動作させる。

* 画像の拡大・縮小
* 画像の移動
* 画面のスクロール
* ボタンのタップ
* メニューの切り替え
* スライダー操作
* マーカーの配置・移動・サイズ変更
* 画像アニメーション関連の操作
* 液体演出の仮想スティック操作
* その他の既存タッチ操作

特に、タッチイベントやPointer Eventsの処理を変更する場合は、既存機能のイベント処理との競合に注意すること。

preventDefault() をアプリ全体のタッチイベントに無条件で適用することは禁止する。

スクロールやピンチ操作など、既存の正常な操作まで一括で無効化しないこと。

6. 文字入力が必要な箇所の例外

スマホ版全体で選択を無効化する方針だが、文字入力が必要な要素については例外とする。

例えば以下。

* テキスト入力欄
* 検索欄
* タグ入力欄
* メモ入力欄
* その他のフォーム入力要素

これらは文字入力・編集が正常にできるようにする。

必要に応じて user-select: text を設定する。

入力欄でのカーソル移動、文字選択、コピー・貼り付けなどの標準操作は維持する。

また、入力欄以外でも、現在実装されている明示的な文字編集機能があれば、その操作を壊さないこと。

7. CSSの適用方針

スマホ版に限定して適用する。

例えば以下のような指定を基本とする。

/* スマホ版アプリ全体 */
.mobile-app {
  -webkit-user-select: none;
  user-select: none;
  -webkit-touch-callout: none;
}
/* 文字入力要素は例外 */
.mobile-app input,
.mobile-app textarea,
.mobile-app [contenteditable="true"] {
  -webkit-user-select: text;
  user-select: text;
}

実際のクラス名やDOM構造は既存コードを調査して決定すること。

上記は実装方針の例であり、既存のCSS構造を無視してそのまま追加することは避ける。

必要であればスマホ版のルート要素に適用し、個別のメニューに設定漏れが生じない構成にすること。

8. 動作確認

スマホ版の実機で以下を確認する。

テキスト選択

* メニューを長押ししても文字選択が発生しない。
* アイコンやボタンのラベルを長押ししても選択状態にならない。
* 画像一覧の文字列を長押ししても選択ハンドルが表示されない。
* 拡大表示画面のメニューでも発生しない。

画像操作

* 画像を長押ししてもブラウザ標準の画像操作メニューが表示されない。
* 画像をドラッグしてもブラウザ標準の画像ドラッグが発生しない。
* アプリ独自の画像移動・拡大操作は正常に動作する。

既存操作

* 通常のタップ操作が正常。
* 画面スクロールが正常。
* ピンチによる拡大縮小が正常。
* メニュー切り替えが正常。
* 液体演出の仮想スティックが正常。
* 長押しやドラッグを使う既存機能に悪影響がない。
* 入力欄では文字入力や編集が正常。

自動テストだけでなく、可能な限り実機でも確認すること。

9. 既存機能への影響を防ぐ

* PC版のテキスト選択・画像選択の挙動は変更しない。
* スマホ版のアプリ独自の操作を無効化しない。
* 既存のタッチイベント処理を不用意に変更しない。
* 無関係なUIやレイアウトを変更しない。
* 文字入力が必要な箇所を壊さない。

既存コードを確認してから、必要な範囲だけを修正すること。

10. バージョン更新

実装完了後、PC版の「詳細」パネルに表示されるバージョン情報を更新する。

表記形式：

Ver.YYMMDDHHMM

実際の作業完了日時を使用し、日本時間を基準に正確な年月日時分を設定すること。

未来の日時や推測した日時を設定しないこと。
